# Caveman Cowork Marketplace

Cowork-compatible distribution of the open-source Caveman project.

Upstream:
https://github.com/JuliusBrussee/caveman

Upstream version:
2.7.0

This distribution contains only:

- Caveman Agent Skills
- Cavecrew agents
- Claude plugin metadata

It deliberately excludes:

- bin/
- installers
- benchmarks
- tests
- unrelated integrations
- duplicate commands
- maintainer agent documentation
- local Claude Code lifecycle hooks

The original Caveman project and its authors retain ownership of the
upstream work. This repository only repackages the Claude-compatible
parts for a smaller hosted/Cowork plugin payload.
